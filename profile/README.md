# OpenPragma

**Open source. Pragmatic by design.**

OpenPragma is an open-source initiative for building software and AI agents that do real work —
reliable, simple to run, and easy to plug into the systems businesses already use.

### Principles
- **Practical:** tools that help solve real problems
- **Integration-first:** built to connect cleanly with existing tools, APIs, and workflows.
- **Transparent:** open code, clear behavior, no lock-in.

### Get involved
Ideas, issues, and contributions are welcome. Open a discussion to get started.
